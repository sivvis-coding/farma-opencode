# Fuentes y candidatas

Consultadas para identificar posibles capacidades, no incorporadas ni ejecutadas:

- [AWS HCLS: pharmacoepidemiology](https://github.com/awslabs/hcls-agent-skills):
  relevante para diseño; algunas recomendaciones están formuladas de forma
  demasiado universal. La skill propia las trata como opciones contextuales.
- [MedSci Skills](https://github.com/aperivue/medsci-skills): limpieza,
  protocolos, referencias y análisis.
- [AIPOCH medical research skills](https://github.com/aipoch/medical-research-skills):
  diseño observacional, evidencia y escritura.
- [BiostatAgent](https://github.com/choxos/BiostatAgent): agentes R y estadística.
- [Office Agent Skills](https://github.com/AlpaZZ/office-agent-skills) y
  [Office DOCX Skills](https://github.com/wintersdragon-c/office-docx-skills):
  posibles opciones para Word y control de cambios; sin pruebas aquí.
- [REDCap agent kit](https://github.com/caiofabio1/redcap-agent-kit) y
  [mcp-server-redcap](https://github.com/msicilia/mcp-server-redcap): candidatos
  MCP, no instalados. El segundo ofrece también operaciones de escritura y borrado.
- [SPIRIT y CONSORT](https://www.consort-spirit.org/) y
  [EQUATOR](https://www.equator-network.org/): guías de reporte.

Antes de incorporar una dependencia externa, revisar licencia real, versión,
código, scripts, seguridad, compatibilidad con Windows/OpenCode y limitaciones.
Las skills propias de este paquete no copian esas instrucciones.
