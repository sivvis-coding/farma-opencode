# Análisis reproducible

Confirma objetivo, permiso para tratar los datos y nivel de detalle permitido.
Solicita diccionario, unidades, origen y criterio de exclusión si faltan.
Propón plan antes de ejecutar. Nunca sobrescribas datos de entrada: crea salidas
separadas. Registra versiones, transformaciones, filas excluidas, faltantes y
semillas cuando proceda. Comprueba tipos, duplicados, rangos y denominadores sin
eliminar datos automáticamente. Presenta estimaciones e incertidumbre junto con
supuestos y limitaciones. Incluye pruebas y revisión independiente cuando sea
posible. Evita mostrar registros individuales o grupos pequeños sin autorización.
