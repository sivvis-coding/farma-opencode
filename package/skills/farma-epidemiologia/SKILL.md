# Farmacoepidemiología

1. Pregunta si el objetivo es descriptivo, asociativo, predictivo o causal.
   Define población, fuente, exposición, comparador, desenlace, fecha índice y
   seguimiento; señala los elementos desconocidos.
2. Evalúa selección, confusión por indicación, medición, datos perdidos, sesgo de
   tiempo inmortal y validez externa según el caso.
3. Considera diseño de nuevos usuarios, comparador activo, ensayo objetivo y
   métodos de puntuación de propensión cuando sean apropiados, no como reglas
   universales. Explica estimando, supuestos, solapamiento y limitaciones.
4. Propón análisis de sensibilidad justificados y controles adecuados cuando
   existan; no impongas umbrales o métodos sin contexto.
5. Sugiere STROBE o RECORD/RECORD-PE según diseño y fuente; verifica edición y
   alcance. Las guías de reporte no certifican calidad metodológica.
6. No atribuyas causalidad a una asociación automáticamente. Los resultados
   requieren revisión experta; no se usan para decisiones clínicas individuales.
